<strong>mpcVisualEditor (mpcVE)</strong>

Author: Arthur Shevchenko (<a href="https://t.me/ShevArtV">https://t.me/ShevArtV</a>)


<strong>Вступление</strong>

Визуальный фронт-редактор контента для сайтов на <strong>migxpageconfigurator</strong> (mpc). Администратор правит содержимое страниц прямо на фронте (inline), не заходя в админку. Сохранение идёт в те же хранилища, что использует mpc: TV <em>mpc_config</em>, lexicon-файлы (переводы), нативные поля ресурса и произвольные TV.


<strong>Что умеет</strong>

<ul>
    <li>Inline-редактирование прямо на странице, по одному полю: правка сохраняется сразу, без перезагрузки и без перезаписи всей страницы.</li>
    <li>Поля любого типа: текст, <em>textarea</em>, форматированный текст (RTE), ссылки, изображения, <em>picture</em>/<em>video</em>/<em>audio</em>, а также TV-типы <em>listbox</em>, <em>checkbox</em>, <em>tags</em>, число, дата, файл.</li>
    <li>Списки (повторяющиеся блоки): добавление, удаление и перетаскивание строк, загрузка картинки в строку.</li>
    <li>Боковая панель секций: порядок (drag-drop), показ/скрытие секции, переключение «статическая секция».</li>
    <li>Панель скрытых полей: правка полей, которых нет в разметке страницы (настройки секции, стили, произвольные поля). Требует mpc 2.5.4+.</li>
    <li>Встроенный файловый менеджер (на <em>modMediaSource</em>): обзор, загрузка, создание папок, переименование и удаление, выбор существующего файла — прямо из редакторов изображения, медиа и файловых TV.</li>
    <li>История изменений: кто, когда и что менял, с пословным diff и откатом. Логируются правки и из редактора, и из админки.</li>
    <li>Блокировка ресурса: пока страницу правит один администратор, другой не откроет её на редактирование (TTL = idle-таймаут, настраивается).</li>
    <li>Мультиязычность: правка значений лексиконов с учётом текущего языка.</li>
    <li>Кнопки в тулбаре: очистить кэш сайта, открыть текущий ресурс в админке.</li>
</ul>


<strong>Требования и зависимости</strong>

<ul>
    <li>MODX Revolution 2.8.x</li>
    <li>PHP 7.4+</li>
    <li><strong>migxpageconfigurator</strong> (mpc) 2.4.0+ — ЖЁСТКАЯ зависимость. mpcVE надстраивается над mpc и использует его address-space, edit-mode рендер и фасад. Для панели скрытых полей нужен mpc 2.5.4+.</li>
    <li><strong>pdoTools</strong> (приходит вместе с mpc; нужен для рендера страниц).</li>
</ul>


<strong>Как пользоваться</strong>

<ol>
    <li>Дайте роли пользователей право (permission) <em>mpcve_edit</em> — оно проверяется при входе в режим правки. При сохранении дополнительно проверяется право <em>save</em> на конкретный ресурс (нельзя править чужое в обход).</li>
    <li>Откройте нужную страницу с query-параметром: <code>?mpcedit=1</code> (имя параметра задаётся настройкой <em>mpcve_edit_param</em>, по умолчанию <em>mpcedit</em>).</li>
    <li>На странице появятся маркеры редактируемых блоков и тулбар. Кликаете блок — правите в открывшемся редакторе — изменение сохраняется сразу в хранилище mpc.</li>
</ol>

Мастер-выключатель всего пакета — системная настройка <em>mpcve_active</em>. Для работы также требуется включённая настройка <em>mpc_edit_mode</em> (пакет <strong>migxpageconfigurator</strong>) и перенарезка страниц — иначе в чанках нет <em>data-mpc-*</em> маркеров и редактор не подключится (предупреждение пишется в системный лог).


<strong>Системные настройки</strong>

<ul>
    <li><em>mpcve_active</em> — включить/выключить пакет (по умолчанию: Да).</li>
    <li><em>mpcve_edit_param</em> — query-параметр входа в режим правки (по умолчанию <em>mpcedit</em> → <code>?mpcedit=1</code>).</li>
    <li><em>mpcve_permission</em> — имя требуемого permission (по умолчанию <em>mpcve_edit</em>).</li>
    <li><em>mpcve_max_upload</em> — лимит размера загружаемого изображения, байт (по умолчанию <em>10485760</em> = 10 МБ; <em>0</em> — без лимита).</li>
    <li><em>mpcve_lock_ttl</em> — TTL блокировки ресурса = idle-таймаут, сек (по умолчанию <em>300</em>).</li>
    <li><em>mpcve_allowed_attrs</em> — белый список HTML-атрибутов для очистки содержимого редактируемого поля (по умолчанию <em>class,href,src,alt,title</em>). Обработчики <code>on*</code>, <code>javascript:</code> и опасный <code>style</code> режутся всегда, независимо от этой настройки.</li>
</ul>
