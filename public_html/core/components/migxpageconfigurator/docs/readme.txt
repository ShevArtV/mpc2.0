## Вступление.
Компонент предназначен для повышения гибкости работы с контентом сайта. Позволяет ускорить интеграцию вёрстки с Modx Revolution.

Основные возможности:
1. Автоматическое создание элементов сайта плагины, чанки, шаблоны, сниппеты, ресурсы, TV.
2. Автоматическая расстановка в вёрстке плейсхолдеров, вызовов сниппетов, чанков.
3. Автоматическое создание файлов чанков, форм, вызовов сниппетов.
4. Автоматическое заполнение контентом админки сайта.
5. Возможность редактировать вёрстку в одном месте.
6. Встроенная ленивая загрузка изображений.
7. Удобное управление контактами и формами из админки.

## Начало работы

Чтобы работать с компонентом было комфортнее рекомендую:
1. Прочитать документацию или в папке `core/components/migxpageconfigurator/documentation` или на сайте <a href="https://docs.modx.pro">https://docs.modx.pro</a>

## Служебная информация.
К служебной информации можно отнести любые части шаблонов, которые есть на всех страницах и не зависят от ресурса (например фавикон, логотип, метрики и т.д.).
Служебная информация записывается в ТВ `service_info` ресурса из системной настройки `site_start`.
Для обозначения служебной информации в шаблоне используется атрибут `data-mpc-info` с указанием ключа служебной информации. Из коробки доступны следующие ключи
1. favicon
2. favicon_apple
3. logo
4. logo_alt
5. logo_mini
6. metrics
Для добавления собственных ключей необходимо отредактировать конфигурацию MIGX с именем `mpc_service_info`.
Для служебной информации доступен вывод по условию. Чтобы задать условие используйте атрибут `data-mpc-cond` с указанием условия без оператора `if`.


## Работа с контактами
Контакт может быть одного из следующих типов:
1. Телефон
2. Email
3. Соц. сеть
4. Адрес
5. Карта
6. Время работы
7. Реквизит
8. Мессенджер

Контакты группируются по значению. Один контакт может иметь несколько мест размещения на странице (напрмер в шапке и в подвале).
Места размещения контактов определяются разработчиком и должны быть представлены ключом из латинских букв, цифр и знака подчеркивания (например `header` и `footer`).

## Работа с данным ресурсов
Есть поддержка работы с основными полями ресурса, с ТВ и конфигурацией страницы. Для указания того куда складывать значение используется атрибут `data-mpc-table`:
1. `res` - поля ресурса;
2. `tv` - переменные шаблона;
3. `config` - конфигурация страницы используется по умолчанию.

Так же необходимо указать id ресурса в атрибуте `data-mpc-rid`.
